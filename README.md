## ✨ ویژگی‌ها

### 🎯 بکاپ هوشمند
- **سه مسیر پیش‌فرض** بدون هیچ تنظیمی: `Claude-3p`، `9router` و پوشه `.claude` (تنظیمات و تاریخچه Claude Code)
- **مسیرهای سفارشی بی‌نهایت** — هر پوشه یا فایلی که می‌خوای، با دکمه «مسیرهای سفارشی...» اضافه/حذف کن
- **فایل‌های بزرگ؟ اصلاً مهم نیست** — فایل تکی بزرگ‌تر از ۱۰۰MB به‌صورت خودکار به تکه‌های ۹۸MB شکسته می‌شه (`*.c9chunk`) و موقع بازیابی با **تطبیق اندازه** دوباره سر هم می‌شه
- **Snapshot ویندوز (VSS)** — برنامه‌ای که فایلش بازه؟ مهم نیست! بکاپ از داخل Snapshot لحظه‌ای درایو گرفته می‌شه؛ بدون بستن برنامه، بدون خطا، بدون کرش
- **جایگزینی امن بکاپ قبلی** — اول بکاپ محلی کامل ساخته و کنترل می‌شه، بعد به Drive آپلود می‌شه؛ فقط اگه همه‌چیز موفق بود، فایل‌های بکاپ قبلی پاک می‌شن 🛡️

### ☁️ گوگل درایو — با حساب خودت
- بکاپ **مستقیماً به Google Drive خودت** آپلود می‌شه — فایل‌ها همیشه قابل مرور، دانلود و اشتراک‌گذاری هستن
- **بدون هیچ وابستگی بیرونی** — احراز هویت OAuth، JWT و آپلود/دانلود همه با پایتون خالص داخل خود برنامه؛ روی ویندوز کاملاً تازه هم بدون نصب هیچی کار می‌کنه
- **Refresh Token منقضی نمی‌شه** — یکبار تأیید می‌کنی، برای همیشه وصل می‌مونه؛ توکن تازه‌سازی خودکار و بی‌صدا انجام می‌شه
- **دسترسی محدود و امن** — برنامه فقط به فایل‌هایی که خودش می‌سازه (scope `drive.file`) دسترسی داره؛ بقیه Drive تو دست‌نخورده می‌مونه
- پوشه مقصد (پیش‌فرض `c9r-backup`) خودکار ساخته می‌شه — فقط آخرین بکاپ در پوشه می‌مونه
- کلیدهای اتصال با **DPAPI ویندوز** رمزنگاری و ذخیره می‌شن

### ⏰ بکاپ خودکار
- فاصله دلخواه: **از ۱ تا ۱۴۴۰ دقیقه** — انتخاب با تو
- انتخابت توی `settings.json` ذخیره می‌شه؛ دفعه بعد همون رو پیش‌نهاد می‌ده
- اگه عملیات قبلی هنوز در حال اجرا باشه، دوره جدید به‌آرامی رد می‌شه (بدون تداخل)

### 🔄 بازیابی کامل
- دانلود همه اجزای آخرین بکاپ از Drive، استخراج امن (ضد zip-slip)، بازگردانی دقیق با کنترل اندازه
- گام‌های پس از بازیابی به‌صورت خودکار: اجرای نصب‌کننده Claude ← `npm i -g npm` ← `npm i -g 9router`
- سازگاری کامل با بکاپ‌های نسخه‌های قبلی

### 🔐 قفل رمز برنامه
- اولین باری که در هر اجرا «بکاپ‌گیری»، «بازگردانی» یا «بکاپ خودکار» را بزنی، رمز پرسیده می‌شود
- رمز **هرگز** در برنامه ذخیره نمی‌شود — فقط هش امن (PBKDF2 با ۲۰۰٬۰۰۰ دور) نگهداری می‌شود و حتی از باینری هم قابل استخراج نیست
- ۵ تلاش با تاخیر تدریجی؛ بعد از اتمام، پنجره بسته می‌شود
- بعد از تأیید، تا بسته شدن برنامه باز می‌ماند

### 🖥️ رابط کاربری
- تم **Liquid Glass** فارسی، راست‌چین، با فونت **وزیرمتن**
- لاگ زنده لحظه‌ای همه عملیات
- ارتقای خودکار به Administrator (فقط وقتی لازمه)

## 🚀 استفاده

| دکمه | کار |
|---|---|
| **بکاپ‌گیری (Backup)** | بکاپ کامل + آپلود به Drive (بکاپ قبلی جایگزین می‌شه) |
| **بازگردانی بکاپ (Restore)** | جدیدترین بکاپ Drive دانلود و دقیقاً برمی‌گرده |
| **بکاپ خودکار** | روشن/خاموش + تنظیم فاصله (۱ تا ۱۴۴۰ دقیقه) |
| **مسیرهای سفارشی...** | افزودن/حذف هر پوشه یا فایل دلخواه |
| **اتصال گوگل درایو...** | اتصال حساب Google (یکبار برای همیشه) |
| **خروج** | بستن برنامه |

### 🔌 راه‌اندازی گوگل درایو (فقط یکبار)

برنامه از OAuth Client (نوع **Desktop app**) خودت استفاده می‌کنه — ۳ دقیقه در [Google Cloud Console](https://console.cloud.google.com):

1. پروژه بساز یا انتخاب کن → **APIs & Services → Library → Google Drive API → Enable**
2. **OAuth consent screen**: External → نام برنامه → ایمیل خودت → save؛ بعد در بخش **Test users** ایمیل خودت رو اضافه کن
3. **Credentials → Create Credentials → OAuth client ID → Desktop app** → فایل JSON رو دانلود کن
4. توی برنامه: «اتصال گوگل درایو...» → فایل JSON رو انتخاب کن → «ورود به گوگل» → در مرورگر تأیید کن → نام پوشه (مثلاً `c9r-backup`) → «ذخیره و فعال‌سازی»

تمام! پوشه خودکار ساخته می‌شه و بکاپ‌ها می‌رن اونجا.

**خط فرمان:**
```bash
Claude9RouterTool.exe                # رابط گرافیکی
Claude9RouterTool.exe --selftest    # خودآزمایی داخلی (بدون شبکه)
Claude9RouterTool.exe --shot out.png # رندر پنجره برای تست ظاهر
```

**فایل‌های پیکربندی:**

| فایل | محتوا |
|---|---|
| `%LOCALAPPDATA%\Claude9RouterTool\custom_paths.json` | مسیرهای سفارشی بکاپ |
| `%LOCALAPPDATA%\Claude9RouterTool\settings.json` | تنظیمات (فاصله بکاپ خودکار، شناسه پوشه و ...) |
| `%LOCALAPPDATA%\Claude9RouterTool\secrets.dat` | اعتبارنامه اتصال (رمزنگاری‌شده با DPAPI ویندوز) |
| `%LOCALAPPDATA%\Claude9RouterTool\gd_state.json` | شاخص آخرین بکاپ آپلودشده |
| `%LOCALAPPDATA%\Claude9RouterTool\logs\` | لاگ کامل هر عملیات |
| `%LOCALAPPDATA%\Claude9RouterTool\backups\` | بکاپ‌های محلی (قبل از آپلود) |

## ⚙️ نحوه کار

```
┌─────────────────────────── بکاپ ───────────────────────────┐
│  1. Snapshot (VSS) از درایوهای لازم ساخته می‌شود            │
│  2. فایل‌ها جمع‌آوری و فایل‌های >۱۰۰MB تکه‌تکه می‌شوند       │
│  3. زیپ‌های ≤۹۸MB ساخته می‌شوند + مانیفست JSON + لاگ        │
│  4. ✓ اعتبارسنجی: همه اجزای محلی سالم‌اند؟                 │
│       ├─ خیر → توقف؛ Drive دست‌نخورده                      │
│       └─ بله ↓                                             │
│  5. ⬆ همه اجزا + مانیفست + لاگ به پوشهٔ مقصد آپلود می‌شوند  │
│  6. 📋 شاخص بکاپ (شناسه فایل همه اجزا) آپلود می‌شود        │
│  7. 🗑 فایل‌های بکاپ قبلی پوشه حذف می‌شوند                  │
│     (اگر آپلود ناقص بماند، خودکار پاک‌سازی و بکاپ قبلی      │
│      حفظ می‌شود)                                            │
│  8. Snapshot پاک‌سازی می‌شود                                │
└────────────────────────────────────────────────────────────┘
```

**فرمت بکاپ:** `backup_YYYYMMDD_HHMMSS_partN.zip` + تکه‌های `*_bigNofM.c9chunk` + مانیفست JSON (فهرست کامل فایل‌ها، مسیرها، اندازه‌ها، تکه‌ها و هشدارها) + شاخص Drive. بازیابی از روی مانیفست انجام می‌شه — یعنی حتی پوشه‌های خالی هم بازسازی می‌شن.

**نکته:** فقط **آخرین بکاپ** در پوشه باقی می‌مونه (رفتار جایگزینی) — فایل‌های بکاپ قبلی خودکار پاک می‌شن.

## ❓ سوالات رایج

**بکاپ چقدر طول می‌کشه؟** به حجم `.claude` و مسیرهای سفارشیت بستگی داره؛ فشرده‌سازی + آپلود معمولاً چند دقیقه‌ست.

**برنامه‌ای که فایلش بازه رو بست؟** نه! Snapshot ویندوز (VSS) کار خوندن رو انجام می‌ده. فقط اگه VSS در دسترس نباشه، به روش معمولی ادامه می‌ده و در لاگ اطلاع می‌ده.

**بکاپ قبلی‌هام کی رفتن؟** طبق طراحی، هر بکاپ جایگزین قبلی می‌شه — فایل‌های بکاپ قبلی از پوشه پاک می‌شن و فقط آخرین نسخه سالم می‌مونه.

**فضای Drive چطور؟** بکاپ از سهمیه ۱۵GB حساب خودت کم می‌شه (فایل‌ها مالکیت حساب خودت رو دارن). فایل‌های بکاپ زیپ‌شده‌ان، پس معمولاً خیلی کوچیک‌تر از حجم واقعی هستن.

**امنیت اتصال چطوره؟** کلاینت OAuth و Refresh Token با DPAPI ویندوز رمزنگاری می‌شن — فقط همین کاربر ویندوز روی همین سیستم می‌تونه بازشون کنه. دسترسی برنامه با scope محدود `drive.file` فقط به فایل‌های ساختهٔ خودش محدود می‌شه.

**آیا اپ گوگل «تأییدنشده» است؟** چون فقط برای استفاده شخصیه، در حالت Testing با آزمونگر بودنِ خودت کامل کار می‌کنه؛ Refresh Token منقضی نمی‌شه.

**خودآزمایی چی‌کار می‌کنه؟** توی یه سندباکس موقت، کل چرخه بکاپ→تکه‌تکه‌سازی→بازیابی رو **بدون شبکه و بدون اجرای نصب‌کننده‌ها** تست می‌کنه — کاملاً بی‌خطره.
